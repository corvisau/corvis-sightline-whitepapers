Sightline runs as one extension in Visual Studio Code.

## Visual Studio Code

Sightline, which includes Lamina, Tetra and Metron, needs VS Code 1.118.0 or later.

## A workspace with your models

A model is a set of plain YAML files in a model directory. Open the folder that holds your models as a VS Code workspace. The apps find each other's files in that workspace. See [Cross-app workflows](/docs/sightline/architecture/cross-app-workflows).

## A licence for editing

You can view models and export from them without a licence. Saving needs a licence that names the app. See [Licensing](/docs/sightline/usage/shared/licensing).

## Optional: a headless browser

The PNG commands that run from a shell need Chromium. See [PNG export in Tetra](/docs/sightline/usage/tetra/png-export).
