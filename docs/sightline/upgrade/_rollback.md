Sightline has no command that undoes an upgrade. This page lists what you can restore, and how to prepare so that you can.

## Roll back Sightline

To go back to an earlier version of Sightline, install the earlier `.vsix` file. Follow the steps in [Install Sightline](/docs/sightline/install/extensions). VS Code replaces the installed version.

Reload VS Code when it asks you to.

## Roll back a model

A model is a set of plain YAML files in a model directory. Keep the model directory under version control, or make a copy before you upgrade Sightline. To roll back, restore the files from the version control system or from the copy.
