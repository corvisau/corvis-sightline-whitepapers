This page takes you from an installed extension to a first assessment. It uses each app once.

Before you start, [install Sightline](/docs/sightline/install/extensions).

## 1. Open a Tetra model

1. Select **Sightline** in the activity bar.
2. Select a `*.tetra.yaml` manifest in the **Tetra** group of the **Models** tree.

To start a new model, run **Tetra: New Model**. See [Open a Tetra model](/docs/sightline/usage/tetra/opening-a-model).

## 2. Narrow the model with a data slice

Use the data slice picker in the toolbar to show part of the model. A data slice is a saved, named filter. See [Data slice filtering](/docs/sightline/usage/tetra/data-slice-filtering).

## 3. Assess the model in Metron

1. Select **Sightline** in the activity bar.
2. Select the `+` action of the **Metron** group in the **Models** tree to create a requirement package.
3. Run **Metron: Apply Package to Model** to bind the package to your Tetra model.

The binding produces a worklist of pairs, each of one requirement and one entity. See [Getting started with Metron](/docs/sightline/usage/metron/getting-started).

## 4. Record an outcome

Open a pair from the worklist. Choose an outcome. Attach evidence and notes. See [Assessment overlay model](/docs/sightline/usage/metron/assessment-overlay-model).

## 5. Raise a finding

Promote the pairs that fail into a finding. See [Findings](/docs/sightline/usage/metron/findings).

## 6. Turn a finding into a risk

In Lamina, open the findings inbox and run **Create cause from finding**. See [Findings inbox](/docs/sightline/usage/lamina/findings).

## Saving your work

You need a licence to save your work. See [Licensing](/docs/sightline/usage/shared/licensing).
