A field in a props drawer can carry a short explanation. A help icon beside the field label opens it as a tooltip.

---

## Reading the help

1. Open the props drawer for an item.
2. Point at the help icon beside a field label, or press Tab until the icon has focus.
3. Read the tooltip.
4. Press Escape to close the tooltip.

The tooltip opens when the icon has keyboard focus, so you do not need a pointer. A screen reader reads the same text as the description of the icon. A field without help has no icon.

## Tetra

Every field that the Tetra drawers show has help. This covers devices, zones, groups, networks, information items, systems, channels and flows. It also covers the fields of one address range, and the name and description of the model itself.

A field that is the same on several items, such as **Description**, **Tags** and **Criticality**, has the same help on each item. A field whose meaning depends on the item has its own text. For example, **Type** on a channel names the kind of link, and **Type** on a flow names the kind of information.

Fields in the **Advanced** section have help in the same way. A field that the drawer hides, or shows as read-only, has no help icon.

## Lamina

Every field that the Lamina drawers show has help. This covers causes, events, outcomes and controls. It also covers the actor, vector and exposure of a cause, the inherent controls of a cause or outcome, the conditional modifiers of an outcome, and the consequence of an outcome.

A field that is the same on several items, such as **Description**, **Tags**, **Template** and **Base Likelihood**, has the same help on each item. A field whose meaning depends on the item has its own text. For example, **Label** on an event, an outcome and a control says that the item needs a label.

The **Template** field has a label and a help icon. A row that opens a sub-drawer, such as **Actor** or **Inherent Consequence**, has its icon beside the row label. Each consequence category, including a category that a risk matrix definition adds, has the same help on its row.

The Template Editor shows the same help beside the fields of a template.

## Metron

Every field that the Metron drawers show has help. This covers requirements, schemes, attribute sets and attributes, and the rule drawer that the rule package editor and Tetra's Rules panel share.

The help is the same when you create an item and when you edit it, including the **ID** and **Label** rows at the top of a create form. A field that repeats, such as **Links**, has the same help on each item.

A field that a widget fills with several controls, such as the outcome list of a scheme or the attribute rows of a requirement, has one help icon beside the field label. The controls inside the widget have none.
