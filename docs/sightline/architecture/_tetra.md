Tetra models networks and systems as block diagrams. A Tetra model is a set of plain YAML files. The extension draws an interactive canvas, a Tabular Editor and a tree view over them.

## What you model

A Tetra model describes zones, groups, devices, networks, channels, flows and information. Templates let an entity inherit a shared body instead of repeating it. See [Templates](/docs/sightline/usage/tetra/templates).

## Views

- **Canvas.** The diagram, with channels and flows drawn over the zones and devices. See [Canvas stacking order](/docs/sightline/usage/tetra/canvas-z-order).
- **Tabular Editor.** The same entities as rows. See [Tabular filtering](/docs/sightline/usage/shared/tabular-filtering).
- **Tree view.** The **Tetra** group of the **Models** tree in the **Sightline** activity-bar view lists the models in the workspace. See [Tree browser panel](/docs/sightline/usage/shared/tree-browser-panel).
- **Props drawer.** The drawer opens the properties of one entity.

## Data slices and layout

A data slice narrows a model with a filter expression. Each slice can also keep its own layout. See [Data slice filtering](/docs/sightline/usage/tetra/data-slice-filtering) and [Per-slice layout](/docs/sightline/usage/tetra/per-slice-layout).

## Overlays

An overlay draws extra information over the canvas. Tetra has a Findings overlay, a Coverage overlay and a legend. See [Overlays](/docs/sightline/usage/shared/overlays), [Findings overlay](/docs/sightline/usage/tetra/findings-overlay), [Coverage overlay](/docs/sightline/usage/tetra/coverage-overlay) and [Legend](/docs/sightline/usage/tetra/legend).

## Output

- Tetra exports the canvas as a PNG. See [PNG export](/docs/sightline/usage/tetra/png-export).
- Tetra generates Word and Excel reports from a model. See [Reports](/docs/sightline/usage/tetra/reports).
