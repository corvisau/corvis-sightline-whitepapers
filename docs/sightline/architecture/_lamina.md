Lamina models risk as bow-tie diagrams. A Lamina model is a set of plain YAML files. The extension draws an interactive canvas, a Tabular Editor, a Template Editor and a report pipeline over them.

## What you model

A bow-tie diagram shows an event with its causes on one side and its consequences on the other. Controls sit on the paths between them. A risk matrix rates each outcome. Each matrix declares the consequence categories that Lamina rates. See [Risk matrix likelihood scale](/docs/sightline/usage/lamina/risk-matrix-likelihood-scale).

## Views

- **Canvas.** The bow-tie diagram.
- **Tabular Editor.** The same entities as rows. See [Tabular filtering](/docs/sightline/usage/shared/tabular-filtering).
- **Tree view.** The **Lamina** group of the **Models** tree in the **Sightline** activity-bar view lists the models in the workspace. See [Tree browser panel](/docs/sightline/usage/shared/tree-browser-panel).
- **Props drawer.** The drawer opens the properties of one entity. See [Authoring controls](/docs/sightline/usage/lamina/authoring-controls) and [Props drawer required fields](/docs/sightline/usage/lamina/props-drawer-required-fields).

## Data slices

A data slice pairs a filter expression with an aggregation profile. It gives the toolbar a saved, named view. See [Data slices](/docs/sightline/usage/lamina/data-slices).

## Findings inbox

The findings inbox lists the Metron findings that have no cause yet. **Create cause from finding** turns a finding into a draft cause. See [Findings inbox](/docs/sightline/usage/lamina/findings) and [Cross-app workflows](/docs/sightline/architecture/cross-app-workflows).

## Output

- Lamina exports the diagram as a PNG. See [PNG export](/docs/sightline/usage/lamina/png-export).
- Lamina generates a risk report for each data slice. See [Risk report (PPTX)](/docs/sightline/usage/lamina/risk-report-pptx).
